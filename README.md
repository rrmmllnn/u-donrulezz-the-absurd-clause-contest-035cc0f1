One line, 200 characters at most: an absurd clause hidden deep inside a
terms-of-service agreement. This entry's program writes a single original
English sentence to `/output/entry.txt` — deadpan legal boilerplate that
quietly turns absurd.

## The clause

> Any dispute arising under these Terms shall be resolved by a single game
> of rock-paper-scissors, best of one, witnessed by a notary public, whose
> decision is final and binding.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

The program is deterministic: every run writes the exact same clause.
